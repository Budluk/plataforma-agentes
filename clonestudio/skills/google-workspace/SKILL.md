# Google Workspace CLI
Instale `@googleworkspace/cli`, configure Google Cloud OAuth e autentique o usuário. Prefira `--dry-run` quando disponível. Mostre o escopo da ação e peça confirmação antes de enviar e-mails, excluir arquivos, compartilhar documentos ou alterar eventos. Tokens OAuth ficam no armazenamento seguro do backend/CLI, nunca no frontend. O CLI não é oficialmente suportado pelo Google. Fonte: https://github.com/googleworkspace/cli

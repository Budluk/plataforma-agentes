# Security audit
Use a Skill oficial do Cloudflare instalada pelo script. Faça revisão defensiva e somente em código/sistemas autorizados. Não execute builds ou testes de código não confiável fora de sandbox. Diferencie achados confirmados de hipóteses que precisam validação. Não probe sistemas de terceiros ou produção sem autorização explícita. Consulte o repositório oficial: https://github.com/cloudflare/security-audit-skill

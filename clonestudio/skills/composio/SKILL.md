# Composio
Use SDK oficial e crie sessões por usuário. Solicite consentimento para conectar contas e para ações externas. Guarde `COMPOSIO_API_KEY` somente no backend. Não execute ações de envio, exclusão ou publicação sem autorização correspondente. Fonte: https://github.com/ComposioHQ/composio

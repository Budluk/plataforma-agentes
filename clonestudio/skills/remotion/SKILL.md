# Remotion
Instale as Skills oficiais com `npx skills add remotion-dev/skills`. Use-as para composição, markup, Studio e render. Verifique a licença e os requisitos de runtime do Remotion antes de distribuir vídeos ou o serviço. Fonte: https://github.com/remotion-dev/skills
